# 스토어 등록 정보 — 한국어 (ko)

## 이름
(`_locales/ko/messages.json`의 `extName`에서 자동 입력)

SubSweep - YouTube 구독 정리 도구

## 요약 (최대 132자)
(`extDescription`에서 자동 입력)

업로드가 멈췄거나 더 이상 보지 않는 채널을 찾아 한 번에 구독 취소하세요. 모든 데이터는 브라우저에만 저장됩니다.

## 설명
(대시보드의 해당 언어 ‘설명’ 칸에 붙여 넣기)

```
수백 개의 채널을 구독하고 있지만 실제로 보는 건 몇 개뿐인가요? SubSweep는 더 이상 보지 않는 채널을 찾아 한 번에 구독 취소할 수 있게 도와줍니다.

주요 기능
• 구독 중인 모든 채널과 각 채널의 마지막 업로드 날짜를 보여 줍니다.
• YouTube 시청 기록을 읽어 각 채널을 마지막으로 본 날짜를 표시합니다.
• 정리할 채널을 추천합니다:
  – 업로드 없음: 직접 정한 기간(1~36개월) 동안 새 동영상이 없는 채널
  – 안 보는 채널: 정한 기간 동안 보지 않은 채널
  – 둘 다: 업로드도 없고 나도 보지 않는 채널
• 원하는 만큼 선택해 한 번에 구독 취소하세요. 진행 상황이 표시되고 언제든지 중지할 수 있습니다.
• 마음이 바뀌었나요? ‘구독 취소됨’ 탭에서 클릭 한 번으로 다시 구독할 수 있습니다.
• 보관 목록: 더 이상 추천받고 싶지 않은 채널을 표시하세요.
• 모든 구독 채널을 업로드 및 시청 날짜와 함께 CSV 파일로 내보낼 수 있습니다.
• 라이트/다크 테마 지원. 한국어, English, 繁體中文, 简体中文, 日本語를 지원하며 브라우저 언어에 맞춰 자동으로 바뀝니다.

사용 방법
1. youtube.com을 열고 로그인합니다.
2. 툴바의 SubSweep 아이콘(또는 구독 페이지의 ‘구독 정리하기’ 버튼)을 클릭합니다.
3. ‘스캔 시작’을 누르고 추천 목록을 확인한 뒤, 채널을 선택해 구독을 취소합니다.

개인정보 보호 중심 설계
• SubSweep는 브라우저 탭 안에서만 동작하며, 이미 로그인한 계정으로 YouTube와만 통신합니다.
• 구독 목록, 시청 기록, 스캔 결과는 내 기기에만 저장되며 개발자나 제3자에게 전송되지 않습니다.
• 가입이 필요 없고, 서버도, 분석 도구도, 광고도 없습니다.
• 설정에서 언제든지 SubSweep 데이터를 모두 지울 수 있습니다.

참고 사항
• ‘안 보는 채널’은 YouTube 시청 기록을 기준으로 판단합니다. 시청 기록이 일시중지되었거나 자동 삭제된 경우 남아 있는 기록만 사용합니다. Google Takeout의 watch-history.json 파일을 가져올 수도 있습니다.
• ‘빠르게’ 모드에서는 여러 채널을 한꺼번에 보낸 뒤 구독 목록으로 결과를 확인하고, 확인되지 않은 채널은 자동으로 하나씩 다시 처리합니다. 진행 중에 다른 탭으로 전환해도 되지만 끝날 때까지 YouTube 탭은 닫지 마세요.
• SubSweep는 YouTube 웹사이트 자체와 같은 요청을 사용합니다. YouTube가 웹사이트를 변경하면 SubSweep가 업데이트될 때까지 일부 기능이 동작하지 않을 수 있습니다.

SubSweep는 독립적인 프로젝트이며 YouTube 또는 Google과 제휴하거나 승인·후원을 받지 않았습니다. YouTube는 Google LLC의 상표입니다.
```
